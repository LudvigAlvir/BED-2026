## Terminal commands

### touch

- Command: touch "filename"
- Creates a file in current directory

### mkdir

- Command: mkdir "folder-name"
- Creates a new directory at the current directory

### ls

- Command: ls
- Lists out the files and folders in current directory

### cd

- Command:
- - cd "foldername"
- - cd ..
- Change Directory
- ".." means going "UP" one directory
- "foldername" means go into that directory

### rm

- Command: rm "filename"
- Removes a file

### code

- command:
- - code "directory-name"
- - code .
- Opens directory in "VSCode"

### rmdir / rm -rf

- Command: rmdir "folder-name"
- Deletes a folder

## Git

### git clone

- Command: git clone "url to repository"
- Download that repository
- Clones it down to our computer

### git add

- Commands:
- - git add .
- - git add "filename"
- "." stages all changed files for commit
- "filname" stages specified file for commit

### git commit

- command: git commit -m "What these code changes do"
- Creates a commit (change) to the project

### git push

- Commands:
- - git push
- - git push origin "branch-name"
- Pushes(uploads) code changes to github

### Steps

- add files
- commit changes
- push changes
