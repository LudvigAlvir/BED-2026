What do we need to have a good todo app

(What we need to have on the website, not code)

  • Users MUST be able to add items to the list
  • Users SHOULD be able to remove items from the list
  • Users MUST be able to mark items as done
  • Users SHOULD be able to edit items
  • Items MUST persist between page visits
  • Users SHOULD be able to filter items
  • Users SHOULD be able to clear the list
  • COULD have positive feedback when all items are done

How do we achieve this? technical explanations

Structure (HTML)

  • Form for adding new items
  • Unordered list of items (container for items)

Implementation (js)

  • List items class
    • id
    • title
    • description
    • status
  • list class
    • data: array(list items)
    • add: method for adding items
    • remove: method for removing an item
    • changeItem: method for changing status of item
    • clear: method for emptying the list
    • save: method for persisting list
  • load items: load saved items
  • display list, function for showing it on the web page
